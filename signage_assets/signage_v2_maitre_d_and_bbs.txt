# MAITRE D' — 401 invalid/missing key (beta-floor reservation)

# no jokes on client faults. This one gets an exception BY DESIGN because the

# (malformed key on a live account) should keep the plain diagnostic text;
# the gate for the art is: unknown/absent key = sign; known-but-broken = plain.

# ANIMATION spec (WELCOME_BBS): the retro draw.
#   - The full sign renders like a 2400-baud terminal: characters appear in
#     chunks, not instantly. Implementation: split the frame into ~40-60
#     equal CHUNKS of characters and reveal one chunk every ~1s (Tom's "one
#     chunk a second"), top to bottom. Whole sign assembles over ~45-60s.
#   - For extra period flavor the CONNECT/PROTOCOL/REFINERY lines can type
#     character-by-character (30-50ms/char) while the border fills in chunks
#     around them — modem handshake lines SHOULD feel typed.
#   - The "caller #____" blank can slot a real counter if the server ever
#     exposes one; leave the blank if not (honest absence, house rules).
#   - Shown ONCE per client (first successful connection): extension stores
#     a sentinel (~/.vorth_welcomed or in config state). Never on retries,
#     never on every boot — the joke dies if it plays twice.
#   - Skip conditions: not a TTY, terminal < 60x18, or VORTH_QUIET=1 →
#     print one line instead: "Connected to Vorth — welcome, operator."
